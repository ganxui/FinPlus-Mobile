# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability or include
personal data, credentials, tokens, screenshots of user accounts, or exploit
details in public discussions.

Use GitHub's **Report a vulnerability** action in the Security tab of this
repository. Reports submitted there are visible only to the reporter and the
repository maintainers while they are being assessed.

Include only the minimum information required to reproduce the issue. Remove
or redact all real user and financial data. We will acknowledge a valid report
and coordinate remediation and disclosure privately.

## Scope

This public repository contains the Android client shell only. FinPlus backend
source code, production configuration, databases, user data, API credentials,
and Android release signing keys are not part of this repository.
